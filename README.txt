CINEMA — приложение для продажи билетов (Windows Forms, .NET 8)

Роли:
- Покупатель: просмотр списка фильмов, подробной информации и покупка билетов.
- Администратор: все разделы и функции управления кинотеатром.

Демонстрационная учётная запись администратора:
Логин: admin
Пароль: admin123

Покупатель вводит своё имя при входе. Оно автоматически подставляется при оформлении покупки.

Для запуска требуется Windows, .NET 8 SDK и SQL Server LocalDB.
Откройте CinemaTickets.sln в Visual Studio и запустите проект.


Изменения интерфейса покупателя:
- Сначала выбирается дата, затем фильмы отображаются вертикальными карточками с прокруткой.
- Под каждым фильмом показываются доступные сеансы выбранной даты отдельными кнопками времени и цены.
- После выбора сеанса можно выбрать свободные места и оформить покупку в этом же разделе.
- Администратор продолжает создавать сеансы в прежнем разделе «Сеансы».
- Сеанс автоматически получает статус «Завершён» по окончании продолжительности фильма. Проверка выполняется при запуске приложения и далее каждую минуту; билеты и история продаж сохраняются.
